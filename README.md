🎮 RPGGame

一个基于 Unity 引擎开发的角色扮演类游戏项目，使用 C# 编写游戏逻辑，主要用于学习和实践游戏开发相关技术。

📖 项目简介

RPGGame 是一个使用 Unity 开发的角色扮演游戏项目，旨在探索角色扮演类游戏的设计与实现，实践游戏场景搭建、交互逻辑编写以及游戏系统开发。

通过本项目，可以进一步熟悉 Unity 游戏开发流程，提高 C# 编程能力和游戏项目开发经验。

✨ 项目特点
🎮 游戏玩法开发： 实践游戏交互逻辑与基础玩法设计。
🗺️ 场景设计： 使用 Unity 进行游戏场景搭建与资源管理。
⚔️ 角色扮演玩法： 为角色扮演类游戏相关系统的设计与实现提供实践基础。
💻 代码开发： 使用 C# 编写游戏逻辑，探索游戏功能的实现方式。

注：以上为项目方向介绍，具体已实现的功能请以仓库中的实际代码为准。

🚀 如何运行
环境准备
安装 Unity Hub。
安装与本项目兼容的 Unity Editor 版本。
安装 Git（如果需要通过 Git 克隆项目）。
获取项目

在终端中执行以下命令：

git clone https://github.com/XianWang12/RPGGame.git
打开项目
启动 Unity Hub。
点击「添加」，选择克隆后的 RPGGame 项目文件夹。
使用兼容的 Unity Editor 版本打开项目。
在 Assets 目录中找到游戏主场景。
打开场景后，点击 Unity 编辑器顶部的「播放」按钮运行游戏。
