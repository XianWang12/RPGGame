# RPGGame —— 2D 类银河恶魔城游戏

一个基于 **Unity 2022.3** 与 **C#** 开发的 2D 动作冒险游戏项目。项目包含角色状态机、敌人 AI、Boss 战斗、多种主动技能、装备与背包、材料合成、角色属性、检查点以及本地存档等系统，重点实践面向对象设计与游戏系统模块化。

## 项目简介

RPGGame 是一款以横版动作战斗和角色成长为核心的 2D 类银河恶魔城游戏。玩家可以在场景中移动、跳跃、冲刺并与敌人战斗，通过技能、装备和属性系统增强角色能力。项目包含普通骷髅敌人及拥有独立状态逻辑的 Boss，并围绕物品管理、技能成长和数据持久化构建了较完整的游戏系统。

项目的主要开发重点包括：**分层有限状态机、技能模块化、背包/装备/仓库管理、属性修饰器、合成流程和 JSON 本地存档**。

## 核心功能与技术实现

### 1. 玩家状态机与动作控制

- 使用有限状态机（FSM）管理玩家行为，将待机、移动、跳跃、空中、冲刺、墙面滑行、墙跳、普通攻击、反击、瞄准/施放技能、死亡等行为拆分为独立状态。
- 通过统一的状态机和状态基类组织状态切换，减少玩家控制器中集中堆叠行为判断的情况。
- 使用动画触发器衔接动画事件与角色逻辑，便于将动画播放和具体动作阶段关联起来。

### 2. 普通敌人与 Boss AI

- 普通敌人使用独立状态类组织待机、移动、战斗、攻击、受击硬直和死亡等行为。
- Boss 拥有单独的状态体系，包含待机、移动、战斗、攻击、施法、传送和死亡等状态。
- Boss 可向玩家所在区域施放法术，并根据竞技场范围寻找传送位置；通过冷却时间和概率控制施法、传送行为。
- 将不同敌人的行为放在各自的状态类中管理，便于调整敌人行为并扩展新的敌人类型。

### 3. 多种技能与战斗效果

项目包含多个独立技能类与对应控制器，例如：

- **冲刺与闪避：** 支持角色机动和战斗中的位置调整。
- **招架：** 为近身战斗提供防御/反击类操作。
- **剑类技能：** 包含剑的释放、控制及相关动画逻辑。
- **水晶、黑洞与分身技能：** 通过独立技能类实现不同的技能效果。
- **雷击及火焰、冰霜相关效果：** 将技能控制与具体效果逻辑分离。

技能系统通过 `Skill` 基类统一冷却计时、使用条件和技能调用入口；具体技能继承基类实现各自的效果。技能管理器负责集中管理技能对象，降低玩家输入逻辑与具体技能实现之间的耦合。

### 4. 背包、装备与仓库

- 使用背包、装备栏和仓库三类容器分别管理物品。
- 使用 `List` 维护物品集合，并通过 `Dictionary` 建立物品数据与物品实例之间的映射，兼顾遍历和查询需求。
- 支持物品添加、堆叠、移除、装备穿戴及同类型装备替换。
- 通过物品数据类区分普通物品与装备数据，并由对应 UI 槽位显示物品、装备和属性信息。
- 将物品数据管理与界面显示分开组织，便于维护容器逻辑和 UI 刷新流程。

### 5. 材料合成与物品效果

- 提供合成窗口、合成列表与合成槽位等 UI 组件，组织配方展示和制作交互。
- 在制作流程中检查所需材料，并处理材料消耗与合成结果。
- 通过物品效果基类组织不同类型的使用效果，包含治疗、火焰、冰霜、雷击以及冻结敌人等效果实现。
- 将物品数据、物品效果和 UI 交互拆分，便于扩展新的物品及效果类型。

### 6. 角色属性与战斗计算

- 使用统一的属性结构管理力量、智力、伤害、暴击率、暴击伤害、生命值、护甲、闪避、魔法抗性及火焰/冰霜/雷电伤害等属性。
- 通过属性修饰器为装备或限时效果增加、移除属性加成，支持多个修饰效果共同影响最终属性值。
- 战斗计算包含暴击、护甲减伤、魔法伤害与抗性处理。
- 实现燃烧、冰缓和感电等异常状态，并结合持续时间、持续伤害或额外雷击效果处理状态影响。
- 通过生命值变化回调等机制，为血条等 UI 提供更新入口。

### 7. 存档与数据持久化

- 使用 `ISaveManager` 统一存档模块的接口，便于不同系统参与保存和读取。
- 使用 `GameData` 集中保存关键数据，包括货币、技能树解锁状态、背包物品、装备、检查点状态、最近检查点和音量设置。
- 通过 `JsonUtility` 将数据序列化为 JSON，并使用本地文件读写实现保存、读取和删除。
- 使用可序列化字典结构保存需要键值映射的数据。
- 存档模块提供可选的数据变换处理开关；该实现属于简单异或处理，不应视为安全的加密方案。

### 8. 检查点、界面与音频

- 使用检查点组件记录检查点激活状态，并在存档中保存相关数据。
- 提供游戏内 UI、Boss 生命条、角色生命条、物品提示、技能提示、技能树、属性面板、合成窗口和设置界面等组件。
- 通过独立的音频管理器组织游戏音频相关逻辑。
- 使用视差背景脚本增强场景的层次感。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Unity 2022.3.62f3c1 | 游戏引擎与项目编辑环境 |
| C# | 游戏逻辑与系统开发 |
| 有限状态机（FSM） | 玩家、普通敌人与 Boss 的行为管理 |
| 面向对象设计 | 技能、敌人状态、物品效果等模块化实现 |
| `List` / `Dictionary` | 背包、装备、仓库及数据组织 |

## 主要脚本结构

```text
Assets/Scripts/
├── Controllers/          # 技能与技能效果控制器
│   └── Skill_Controller/
├── Enemy/                # 普通敌人、骷髅敌人与 Boss 状态机
│   ├── Boss/
│   └── Skeleton/
├── Items and Inventory/  # 物品、背包、装备、掉落与物品效果
│   └── Effects/
├── Manager/              # 游戏管理与音频管理
├── Player/               # 玩家控制器及玩家状态
├── Save and Load/        # 存档接口、数据结构与文件读写
├── Skills/               # 技能基类、技能管理器与具体技能
├── Stats/                # 角色属性、玩家属性与敌人属性
└── UI/                   # 游戏 UI、背包、技能树、属性及合成界面
```

## 如何运行

1. 克隆仓库：

   ```bash
   git clone https://github.com/XianWang12/RPGGame.git
   ```

2. 使用 Unity Hub 添加克隆后的 `RPGGame` 文件夹。
3. 使用 Unity `2022.3.62f3c1` 或兼容版本打开项目。
4. 等待 Unity 导入资源并完成脚本编译。
5. 在 `Assets` 中找到项目场景，打开实际的游戏入口场景。
6. 点击 Unity 编辑器顶部的播放按钮运行。

> 仓库未在本说明中指定唯一主场景名称，请以项目内实际场景文件及构建设置为准。

## 项目中体现的设计思路

- **状态与行为分离：** 通过状态类管理玩家、敌人与 Boss 的不同行为。
- **技能扩展：** 使用技能基类和独立技能实现组织技能调用及冷却逻辑。
- **数据结构分工：** 使用集合存储物品，并通过字典辅助建立物品数据映射。
- **属性效果可组合：** 将基础属性与限时修饰效果分开管理。
- **存档模块解耦：** 通过存档接口与统一数据对象组织多个系统的数据持久化。
